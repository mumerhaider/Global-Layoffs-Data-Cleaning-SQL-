# 🧹 Global Layoffs Data Cleaning in SQL

This project showcases my data cleaning skills using SQL on a real-world dataset of global layoffs. I cleaned, transformed, and standardized raw data to make it analysis-ready.

---

## 📊 Dataset

- **Source**: [Layoffs.csv](https://github.com/AlexTheAnalyst/MySQL-YouTube-Series/blob/main/layoffs.csv)
- **Columns**: Company, Location, Industry, Total Laid Off, Percentage Laid Off, Date, Stage, Country, Funds Raised (USD)

---

## 🛠️ Skills Used

- SQL (CTEs, JOINS, CASE, DATE functions, Aggregations)

---

## 🧾 Tasks Performed

- Removing Duplicates
- Standardizing Data
- Removing Null/Blank Values 
- Removing extra Coloumns

---

## 📁 Files

| File | Description |
|------|-------------|
| `sql/data_cleaning_queries.sql` | SQL script for cleaning the raw layoffs dataset |
| `data/layoffs_raw.csv`          | Original raw dataset |
| `images/`                       | Visuals showing before/after comparisons |

---

## 🧠 Insights (Post-Cleaning)

- Most affected industries and countries
- Trends over time
- Startups vs. large companies comparison
